# Иконка приложения YMusic

Здесь лежит мастер-иконка для iOS. Xcode (`actool`) сам нарежет нужные
размеры при сборке, отдельные `@2x`/`@3x` файлы не нужны.

## Требования

- **Один файл:** `AppIcon-1024.png`, ровно 1024×1024 px.
- **Без альфа-канала** (PNG color type 2 / `Format24bppRgb`). Если сохранить
  с прозрачностью, на домашнем экране вокруг скруглений будет чёрный фон,
  а App Store/actool может выдать предупреждение.
- Без скруглений и без полей «под маску»: iOS сама применяет маску
  `squircle`. Углы должны быть заполнены цветом.
- Формат — PNG (можно HEIC, но PNG предсказуемее).

## Замена

1. Положите новую картинку поверх `AppIcon-1024.png` (имя не менять).
2. Имя набора иконок задано в `project.yml`:
   `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon` — менять не нужно.
3. Пересоберите приложение (CI или `xcodegen generate` + Xcode).
4. На устройстве удалите старую копию приложения перед установкой новой,
   иначе SpringBoard может показать закэшированную иконку.

## Текущая заглушка

Сгенерирована программно: диагональный градиент фирменного красного
(`#EB2E3D` → почти чёрный), белая волна из девяти полос с круглыми
торцами и мягкая подсветка в центре. Альфа-канала нет.
